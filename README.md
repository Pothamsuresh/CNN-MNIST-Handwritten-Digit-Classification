# CNN-MNIST-Handwritten-Digit-Classification
# Convolutional Neural Network (CNN) – MNIST Handwritten Digit Classification

This project demonstrates the implementation of a Convolutional Neural Network (CNN) using the MNIST dataset to recognize and classify handwritten digits from 0 to 9.

The CNN model learns important image features such as edges, shapes, and patterns to accurately identify handwritten digits.

**Key Highlights:**
- Loaded and explored the MNIST dataset.
- Preprocessed and normalized handwritten digit images.
- Built a CNN model using TensorFlow/Keras.
- Trained the model to classify handwritten digits (0–9).
- Evaluated model performance using test data.
- Visualized predictions and model accuracy.

**Technologies Used:**
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Jupyter Notebook

**Objective:** To understand Convolutional Neural Networks and apply deep learning techniques to image classification using the MNIST dataset.
